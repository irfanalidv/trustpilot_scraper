# Security Policy

## Supported versions

Only the latest minor release of `trustpilot_scraper` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/irfanalidv/trustpilot_scraper/security/advisories/new),
or email **irfanali29@hotmail.com** with:

- a description of the issue and its impact
- steps to reproduce (a minimal script is ideal)
- the affected version(s)

You will get an acknowledgement within 72 hours and a fix or mitigation plan within 14 days.
